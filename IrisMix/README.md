# IrisMix 線上體驗

靜態頁面 `/IrisMix/`，以 HTTP 提供檔案即可使用，無需建置或推論伺服器。

## 素材與品質

v3 提供四位模特、六款日常／藝術妝容，共 21 組經檢視的實際 Stage II
輸出。暖光人像搭配睡蓮彩繪的花卉圖案不完整，已排除此組合；緋紅罌粟在夜景／微笑人像上的花形不完整，也已排除。全部人像來自
LayerBeauty 合成成人素材，沒有使用受限制的外部基準資料集。
`assets/v3/manifest.json` 記錄素材、checkpoint、採樣條件與排除原因。
「查看渲染前後」顯示同一組合的幾何轉移及真正保存的 Stage II 輸出。

## 操作

介面以繁體中文為主，提供模特切換、分類、放大參考圖的自由塗選與橡皮擦、
快速選區，以及獨立圖層的強度、色調、排序、顯示與刪除。
整體色調只影響彩妝圖層。復原／重做涵蓋選區、圖層與模特切換；換模特時
會載入對應模特的已渲染圖層。下載只包含已加入的圖層。

512² 選區經由無損 RGB PNG 的逐像素對應映射至模特；每個圖層來自保存的
Stage II 結果，而不是直接貼上 warp。混搭、調色與新選區不會再次執行
生成模型，因此不能視為新的 IrisMix 推論結果。快速體驗頁的混搭與調色使用已渲染圖層；完整瀏覽器推論研究版目前暫停公開。

## 自訂照片

可選取自己的 source／REF，僅在本機預覽並檢查檔案大小、尺寸、人臉數量、
臉部大小、姿態、睜眼、亮度與清晰度。結果不保證彩妝品質；遮擋及美顏等
情況仍須使用者自行確認。自訂照片推論目前暫停開放，此處僅提供本機品質檢查與原圖預覽。

人臉檢查使用固定的本機 MediaPipe Tasks Vision 0.10.21 與 Face Landmarker，
選取照片後才載入所需的 WASM 版本與人臉模型（約 14 MB；全部相容版本合計約 23 MB）。照片不會上傳。第三方元件採 Apache 2.0，
詳見 `vendor/mediapipe/LICENSE.txt`、`NOTICE.txt` 與 `SDK-manifest.json`。
此版本保留上游套件原始內容，JS／WASM 均由本站提供並固定版本，沒有外部遙測連線。

`tools/export_irismix_demo.py` 以 CPU 匯出已完成的真實 Stage II 輸出與幾何映射，
匯出器本身不執行生成模型。離線素材準備使用 FULL/lora_step3000_ema、σ=0.65、
一步採樣；緋紅罌粟則使用真正瀏覽器 C2 → FULL 推論（共用 Q4 底模、FP32 LoRA），並保存實際 Stage I 去妝臉的幾何對應。公開網站不連接 GPU。

## 瀏覽器推論暫停公開

依擁有者要求，完整瀏覽器推論研究版暫停公開，Hugging Face 模型庫已改為私人。
網站移除所有推論入口；`inference/` 的入口頁僅顯示暫停說明，設定停用並清空遠端模型網址。
此 Git 目錄保留程式、runtime、範例及授權供後續維護，沒有模型權重或 ONNX 圖。
`WEBFILES.json` 記錄目前暫停狀態與網頁檔案雜湊。

本機研究包可繼續保留與使用；重新公開須另行取得擁有者指示並解除發布暫停狀態。
既有非商業研究限制與第三方授權見 `inference/MODELS.md`、`inference/licenses/`。

## 驗證

以 Chromium 實際檢查自由塗選、圖層調色與背景不變、下載、復原／重做、
模特切換、21 組可用配對及排除配對、有效照片與不合格照片檢查。
版面檢查涵蓋 320、375、390、768、1024、1440 px。
