# IrisMix 線上體驗

靜態頁面 `/IrisMix/`，以 HTTP 提供檔案即可使用，無需建置或推論伺服器。

## 素材與品質

v3 提供四位模特、六款日常／藝術妝容，共 21 組經檢視的實際 Stage II
輸出。暖光人像搭配睡蓮彩繪的花卉圖案不完整，已排除此組合；緋紅罌粟在夜景／微笑人像上的花形或花梗不完整，也已排除。
柔光、夜景、微笑、暖光四位人像來自 LayerBeauty 合成成人素材。沒有使用受限制的外部基準資料集。
`assets/v3/manifest.json` 記錄素材、checkpoint、採樣條件與排除原因。
「查看渲染前後」顯示同一組合的幾何轉移及真正保存的 Stage II 輸出。

## 操作

介面以繁體中文為主，依「選人像 → 整體妝感 → 眼妝 → 唇色 → 臉部彩繪 → 完成」配妝。
選項照片點選即套用，主按鈕直接標示下一步；選好整體妝感後，各局部步驟都可以保留現況。
同一部位換款會取代先前的選擇，不新增疊加圖層；重選整體妝感會重新開始局部搭配與細修。
可逐部位調整強度、色調、沿用整體或改回原圖。0% 的局部覆寫會顯示該部位原圖，
不會透出被取代的舊妝。同一步反覆點同一款不會累積強度。

電腦版結果固定在右側；手機版保留頂部結果與底部下一步導覽。參考圖可點擊放大。
完成頁整理各部位的選擇，可點「調整」回到該步。復原／重做涵蓋配妝、細修、步驟與模特切換。
自訂「自由塗選與細修」預設收合，保留任意塗抹、橡皮擦、快速選區及細修圖層的排序、
顯示、刪除、強度與色調。細修疊在配妝之上；下載不包含尚未加入的細修預覽。

引導選項依實際可用部位篩選：眼妝四款、唇色三款、彩繪一款，再與模特的品質通過配對交集。
跨眼睛的緋紅罌粟保留於整體妝感，避免局部裁切花朵；幾乎沒有唇色變化的款式不列為獨立唇色。

配妝使用固定於模特座標的眼、唇與臉部區域，互斥權重混合保存的 Stage II RGBA，
從原圖重建每次結果，避免換款時重複 alpha 疊加。`assets/guided/regions.json` 記錄
12 張區域遮罩的輸入雜湊與生成方式；`tools/export_irismix_guided_regions.py --write`
以 CPU 從已通過品質檢視的既有幾何映射匯出，不執行生成模型，也不修改 v3 原始素材。

自由塗選的 512² 選區仍經由無損 RGB PNG 對應映射到模特，使用保存的 Stage II 結果。
部位搭配、混搭、調色與新選區不會再次執行生成模型，因此不等於新的 IrisMix 推論結果。
不同人像的眼型、光線與膚色會影響效果；完整瀏覽器推論研究版目前暫停公開。

## 自訂照片

可選取自己的 source／REF，僅在本機預覽並檢查檔案大小、尺寸、人臉數量、
臉部大小、姿態、睜眼、亮度與清晰度。結果不保證彩妝品質；遮擋及美顏等
情況仍須使用者自行確認。自訂照片推論目前暫停開放，此處僅提供本機品質檢查與原圖預覽。

人臉檢查使用固定的本機 MediaPipe Tasks Vision 0.10.21 與 Face Landmarker，
選取照片後才載入所需的 WASM 版本與人臉模型（約 14 MB；全部相容版本合計約 23 MB）。照片不會上傳。第三方元件採 Apache 2.0，
詳見 `vendor/mediapipe/LICENSE.txt`、`NOTICE.txt` 與 `SDK-manifest.json`。
此版本保留上游套件原始內容，JS／WASM 均由本站提供並固定版本，沒有外部遙測連線。

`tools/export_irismix_demo.py` 以 CPU 匯出已完成的真實 Stage II 輸出與幾何映射，
匯出器本身不執行生成模型。離線素材準備使用 FULL/lora_step3000_ema、σ=0.65、
一步採樣；緋紅罌粟則使用真正瀏覽器 C2 → FULL 推論（共用 Q4 底模、FP32 LoRA），並保存實際 Stage I 去妝臉的幾何對應。公開網站不連接 GPU。

新增人像使用 `tools/export_irismix_source.py` 增量匯出，須明列通過檢視的妝容。
預設只顯示計畫，`--write` 才更新素材；既有圖片、遮罩與映射不會被改寫。

## 瀏覽器推論暫停公開

依擁有者要求，完整瀏覽器推論研究版暫停公開，Hugging Face 模型庫已改為私人。
網站移除所有推論入口；`inference/` 的入口頁僅顯示暫停說明，設定停用並清空遠端模型網址。
此 Git 目錄保留程式、runtime、範例及授權供後續維護，沒有模型權重或 ONNX 圖。
`WEBFILES.json` 記錄目前暫停狀態與網頁檔案雜湊。

本機研究包可繼續保留與使用；重新公開須另行取得擁有者指示並解除發布暫停狀態。
既有非商業研究限制與第三方授權見 `inference/MODELS.md`、`inference/licenses/`。

## 驗證

以 Chromium 實際檢查逐步配妝、點選即套用、同部位換款與重複點選不累積、
局部 0% 強度回到原圖且部位外像素不變、沿用整體、清除、部位摘要與返回編輯。
另檢查自由塗選、細修強度與色調、整體換款的原子復原／重做、模特切換、
21 組可用配對及排除配對、背景不變與 640×640 PNG 下載。
版面檢查涵蓋 320、390、720、768、1024、1280、1440 px，並檢查下一步與固定預覽是否遮擋操作。
