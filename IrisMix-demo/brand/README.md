# IrisMix 品牌資產

三片交疊的花瓣，呼應 Iris（鳶尾花）與 Mix（彩妝混搭）；中央的眼形／唇形留白連結彩妝應用。主色延續網站的酒紅，搭配玫瑰與淡粉。

## 檔案

- `irismix-logo.svg`：彩色橫式標誌，優先用於淺色背景。
- `irismix-mark.svg`：獨立彩色圖形。
- `irismix-logo-mono.svg`、`irismix-mark-mono.svg`：單色版本。
- `irismix-logo-inverse.svg`：適合深色背景的反白版本。
- `favicon.svg`：小尺寸單色圖示，依瀏覽器的深淺色偏好切換顏色。
- `irismix-logo.png`、`irismix-mark.png`：高解析透明背景圖片。
- `irismix-brand-preview.png`：識別設計預覽。

所有 SVG 均為可編輯路徑，不依賴外部字型、圖庫、追蹤器或網路服務。文字已轉為向量外框，跨裝置呈現一致。

## 使用

保持原始比例。標誌四周至少保留一片中央花瓣寬度約一半的空間。彩色圖形建議使用於 32 px 以上；16–24 px 優先使用單色圖形。請勿壓扁、旋轉、加陰影或任意調換配色。

品牌色：酒紅 `#7B3548`、玫瑰 `#AD5B6B`、淡粉 `#D39B9E`。搭配暖白 `#F7F4EE` 與深褐 `#302923`。
