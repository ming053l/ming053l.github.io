# IrisMix 線上體驗

靜態頁面 `/IrisMix-demo/`，以 HTTP 提供檔案即可使用，無需建置或推論伺服器。

## 素材與品質

v3 提供四位模特、六款日常／藝術妝容，共 21 組經檢視的實際 Stage II
輸出。暖光人像搭配睡蓮彩繪的花卉圖案不完整，已排除此組合；緋紅罌粟在夜景／微笑人像上的花形或花梗不完整，也已排除。
柔光、夜景、微笑、暖光四位人像來自 LayerBeauty 合成成人素材。沒有使用受限制的外部基準資料集。
`assets/v3/manifest.json` 記錄素材、checkpoint、採樣條件與排除原因。
「查看渲染前後」顯示同一組合的幾何轉移及真正保存的 Stage II 輸出。

## 自由上妝

預設入口是可自由試畫的化妝台，眼影色盤與圓頭暈染刷已準備好；第一筆就能上色，
並自動建立圖層。點「眼影／唇色／腮紅」切換對應色盤，選色或使用自訂色，
直接在結果人像拖曳上色，不需先選參考圖或加入圖層。
提供圓頭暈染刷、扁平刷與斜角刷，以及上色、暈染、橡皮擦三種操作。
刷具選擇預設收合，摘要顯示目前刷具；選色、筆刷大小與濃度保持在主面板。
筆刷大小、濃度、柔和度、延展範圍與方向均實際影響像素；暈染會推開既有顏色。
方向可以跟隨手勢、向外、水平、垂直或自訂角度，游標顯示目前刷具的實際形狀與方向。

「放大檢視」僅改變畫面，筆畫與下載仍使用 640×640 座標。
首次上妝與沒有畫到顏色時，顯示可上色部位的暫時導引；畫成功後收起，亦可手動開關。
導引與工具／圖層提示使用獨立預覽覆蓋，不會出現在下載圖片或原圖比較中。
「開始上妝」直接前往操作區；研究目標與合作資訊保留於操作區下方。
每位人像的手繪內容分開保存；復原／重做包含筆畫、清除、模特切換及重新開始。
取消筆畫或雙指接觸會撤銷尚未完成的筆畫。已畫內容可與參考妝容混合並一起下載。

「妝容圖層」可新增同一部位的獨立圖層；列表上方是前景，選中後可往前／往後排序，
並調整整層強度、色調、顯示／隱藏或刪除。色盤與圖層共用同一個目前選取狀態，
上色、暈染、橡皮擦及清除只修改目前圖層。隱藏的圖層必須先顯示才能作畫；
原圖與參考妝容位於手繪圖層下方。圖層操作與筆畫一起納入復原／重做及下載。
點目前圖層可開啟圖層設定；隱藏或強度為零時，可就地恢復並繼續作畫。
主要操作字體放大，手機版圖層排序鍵保留至少 44 px 觸控高度。

`cosmetic-brush.js` 以 Canvas2D 累積顏料密度，保留底圖明暗與紋理；
這是本機筆刷視覺模擬，不會執行新的 IrisMix 推論。眼球、虹膜可見區、唇內與牙齒
有部位遮罩保護；眼影預設限制於上眼皮，腮紅限制於臉頰。人臉幾何不等於頭髮或遮擋分割，
遮住皮膚的髮絲仍可能需要手動擦除。`makeup-station.js` 負責色盤、指標、檢視與歷史介接。

`assets/cosmetics/face-guides.json` 保存四位模特的精確顯示座標與偵測輸入雜湊，
由 `tools/export_irismix_cosmetic_guides.py --write` 使用本機 Face Landmarker 及 CPU 匯出。
既有照片、模型與 v3 素材未改動；開啟網頁只讀取幾何 JSON，不會載入人臉偵測模型。
單個筆畫、點數、專案筆畫數與圖層數有明確上限，達限時保留既有內容。
圖層使用最多四張顏料暫存，其餘依筆畫重建，避免每加一層就持續增加點陣記憶體。

## 參考妝容

介面以繁體中文為主，依「選人像 → 整體妝感 → 眼妝 → 唇色 → 臉部彩繪 → 完成」配妝。
整體、眼妝與唇色可點選照片直接套用；臉部彩繪會先開啟局部塗選。主按鈕直接標示下一步，各局部步驟都可以保留現況。
預設「疊加多款」支援同一部位複選，再點已選款式即可取消。首款強度為 100%，
同部位後續圖層預設 50%，可逐層調整強度、隱藏、排序與移除；新增整體款式不清除局部或自由筆刷。
「替換部位」只替換目前部位的參考圖層，保留其他部位、任意細修與自由筆刷。
每款皆為可編輯圖層，可調整強度、色調與選區。強度 0% 會透出下方搭配；清空此層選區不改動其他圖層。
複選模式反覆點同一款會取消／重新加入；「選取局部」則可獨立加入同款的不同局部。

在「參考妝容」模式，電腦版結果固定在左側；手機版保留頂部結果與底部下一步導覽。參考圖可點擊放大。
完成頁整理各部位的選擇，可點「調整」回到該步。復原／重做涵蓋配妝、細修、步驟與模特切換。
自訂「自由塗選與細修」預設收合，保留任意塗抹、橡皮擦、快速選區及細修圖層的排序、
顯示、刪除、強度與色調。細修疊在配妝之上；下載不包含尚未加入的細修預覽。

引導選項列出每位模特所有品質通過的參考；柔光人像有六款，其餘人像有五款。眼妝、唇色可直接取用部位或先塗選局部；自然唇色款式有明確標示。
臉部彩繪先開啟局部編輯器，讓使用者塗選花朵、花瓣或任意區域，不自動套滿整張妝。睡蓮與緋紅罌粟優先排列；原先未通過品質的三組來源配對仍排除。

預設部位選區從模特座標的眼、唇與臉部區域映射回參考圖；每層再以 REF 選區
取用保存的 Stage II RGBA，依圖層順序從原圖重建每次結果，避免把上一幀結果反覆疊加。`assets/guided/regions.json` 記錄
12 張區域遮罩的輸入雜湊與生成方式；`tools/export_irismix_guided_regions.py --write`
以 CPU 從已通過品質檢視的既有幾何映射匯出，不執行生成模型，也不修改 v3 原始素材。

自由塗選的 512² 選區仍經由無損 RGB PNG 對應映射到模特，使用保存的 Stage II 結果。
部位搭配、混搭、調色與新選區不會再次執行生成模型，因此不等於新的 IrisMix 推論結果。
不同人像的眼型、光線與膚色會影響效果；完整瀏覽器推論研究版目前暫停公開。

## 自訂照片

可選取自己的 source／REF，僅在本機預覽並檢查檔案大小、尺寸、人臉數量、
臉部大小、姿態、睜眼、亮度與清晰度。結果不保證彩妝品質；遮擋及美顏等
情況仍須使用者自行確認。自訂照片推論目前暫停開放，此處僅提供本機品質檢查與原圖預覽。

人臉檢查使用固定的本機 MediaPipe Tasks Vision 0.10.21 與 Face Landmarker，
選取照片後才載入所需的 WASM 版本與人臉模型（約 14 MB；全部相容版本合計約 23 MB）。照片不會上傳。第三方元件採 Apache 2.0，
詳見 `vendor/mediapipe/LICENSE.txt`、`NOTICE.txt` 與 `SDK-manifest.json`。
此版本保留上游套件原始內容，JS／WASM 均由本站提供並固定版本，沒有外部遙測連線。

`tools/export_irismix_demo.py` 以 CPU 匯出已完成的真實 Stage II 輸出與幾何映射，
匯出器本身不執行生成模型。離線素材準備使用 FULL/lora_step3000_ema、σ=0.65、
一步採樣；緋紅罌粟則使用真正瀏覽器 C2 → FULL 推論（共用 Q4 底模、FP32 LoRA），並保存實際 Stage I 去妝臉的幾何對應。公開網站不連接 GPU。

新增人像使用 `tools/export_irismix_source.py` 增量匯出，須明列通過檢視的妝容。
預設只顯示計畫，`--write` 才更新素材；既有圖片、遮罩與映射不會被改寫。

## 瀏覽器推論暫停公開

依擁有者要求，完整瀏覽器推論研究版暫停公開，Hugging Face 模型庫已改為私人。
網站移除所有推論入口；`inference/` 的入口頁僅顯示暫停說明，設定停用並清空遠端模型網址。
此 Git 目錄保留程式、runtime、範例及授權供後續維護，沒有模型權重或 ONNX 圖。
`WEBFILES.json` 記錄目前暫停狀態與網頁檔案雜湊。

本機研究包可繼續保留與使用；重新公開須另行取得擁有者指示並解除發布暫停狀態。
既有非商業研究限制與第三方授權見 `inference/MODELS.md`、`inference/licenses/`。

## 驗證

以 Chromium 實際檢查三款刷具、上色／暈染／擦除、方向與範圍的像素差異、
眼球及部位外零變更、筆畫取消／雙指取消、跨人像隔離、放大檢視與下載。
另外以同一眼皮的兩層不同顏色驗證排序實際改變像素、反向排序完全還原，
並檢查單層擦除／暈染隔離、隱藏、整層強度與色調、刪除、歷史還原及記憶體上限。
另檢查參考模式的逐步配妝、點選即套用、同部位換款與重複點選不累積、
逐層強度與色調、局部清除、部位摘要與返回編輯。
另檢查自由塗選、細修強度與色調、整體換款的原子復原／重做、模特切換、
21 組可用配對及排除配對、背景不變與 640×640 PNG 下載。
版面檢查涵蓋 320、390、720、768、1024、1280、1440 px，並檢查下一步與固定預覽是否遮擋操作。

參考妝容與自由上妝共用同一張結果；參考打底，手繪疊在上方，切換工具不會清空內容。
複選驗證涵蓋兩款整體加兩款眼妝、實際疊色順序、取消與復原、筆刷共存及 PNG 像素一致。

### 視覺與響應式布局

`kbeauty.css` 統一暖白、霧玫瑰與奶茶色。桌機為左側試妝鏡、右側色盤／參考妝容，手機以精簡固定鏡面保留可見預覽。照片、模型結果與輸出色彩不受介面主題影響。

### 參考圖層的局部筆刷編輯

- 每張參考都有「選取局部」，可先以筆刷塗選、擦除與柔邊，再新增局部圖層。
- 「筆刷編輯／選取局部」可重新修改任何已加入的參考或細修圖層；補回可跨越預設的部位邊界。
- 編輯器支援自己的復原／重做、部位與全妝預設、清空、還原，以及 100% 單層／整體搭配預覽。取消不改動搭配，儲存後全域復原／重做也涵蓋遮罩。
- 替換的整體妝容同樣是一個可編輯圖層，放在已有局部搭配下方；替換其他部位保留其他參考與自由上妝。
- 遮罩以 REF 座標保存，使用既有無損對應表套用保存的模型結果。切換模特會保留選區；已排除配對仍不顯示或提供編輯。
- 手機可切換「塗選參考圖／檢視妝效」，保留大圖供精細選取。
