# 本機瀏覽器檢視紀錄

2026-10-22。此紀錄描述本機檢視包；所有實測均使用瀏覽器 WebGPU，沒有伺服器 GPU 推論或以預渲染結果替代生成。

- 實際照片經過人臉偵測、完整 Stage I 分解、條件圖建立、完整 Stage II 與全圖合成，輸出有效的 1024 × 1024 圖片。
- 完整離線包已用自行上傳的人像與 REF 加上自由塗選完成真正生成，約 105 秒，並成功下載 PNG；觀察到零外部 HTTP 或上傳請求。另已驗證照片品質檢查、取消載入後重試、原圖比較與 GPU 失敗後重新載入。
- 「緋紅罌粟」以四位範例人像實測；僅保留柔光與暖光兩組，夜景及微笑組有遮擋或花梗不連續，介面會說明並停用。
- 介面已檢查 320、375、390、768、1024、1440 px 寬度。完整模型目前仍以桌機使用為主。

寬幅 VAE 的控制實驗中，原版 Bucket 與採用的 lazyRelease 設定輸出共 2,359,296 個數值逐位元一致；測試機額外顯示記憶體峰值約由 21.0 GiB 降至 16.7 GiB。完整模型仍屬高記憶體桌機研究版，建議 24 GB 等級顯示卡，不能保證所有同級裝置或當下可用記憶體皆足夠。

測試環境為 Linux、Chromium 與 NVIDIA Blackwell。先前完整照片推論約 121 秒；實際操作介面的完整生成約 142 秒。這些數字僅描述測試機，不代表其他裝置的速度。尚未宣稱 Safari、Firefox、手機或所有顯示卡皆可執行。

載入前會檢查 WebGPU 及 768 MiB 單一儲存緩衝區的支援；通過此檢查仍須具有足夠的可用顯示記憶體。沒有支援的裝置會顯示說明，不會改以伺服器 GPU 執行。

第三方元件來源與使用限制見 `MODELS.md`；每個檔案的大小及 SHA-256 見 `MODELFILES.json`。完整瀏覽器版需要讓訪客取得執行用權重，擁有者已同意公開研究體驗版；公開部署的固定版本以網站設定為準。
