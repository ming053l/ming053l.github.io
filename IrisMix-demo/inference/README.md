# IrisMix 瀏覽器研究版：暫停公開

擁有者已要求暫停公開瀏覽器推論，Hugging Face 模型庫已改為私人。

`index.html` 為不載入推論程式的暫停說明頁；`model-config.json` 設為 `enabled: false` 並清空模型網址。
快速體驗仍可由上層 `/IrisMix/` 使用，自訂照片僅提供本機品質檢查。

這個 Git 網頁目錄保留程式、runtime、範例照片及授權供後續維護，沒有模型權重或 ONNX 圖。
`REMOTE-MODELFILES.json` 為先前研究版本的來源紀錄，不表示模型目前公開或可下載。
`WEBFILES.json` 記錄暫停狀態與目前檔案的 SHA-256。

本機研究包與既有驗證紀錄保留。重新公開須取得擁有者指示；相關第三方條款見 `MODELS.md`、`licenses/`。
